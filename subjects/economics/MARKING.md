# EcBiz Economics on-device marking

Open Economics → Practice Questions and choose **Download local AI**. EcBiz uses the public, WebLLM-converted Llama 3.2 1B model for text. The browser caches the first model download and reuses the loaded model for marking in the same tab. Submitting a diagram may load the separate Phi 3.5 Vision model. Downloads require a connection and a WebGPU-capable browser and device. There is no API key, ChatGPT sign-in or hosted marking endpoint.

The mark scheme supplies the criteria for written grades. Discussion questions use Cambridge-style bands, and multiple-choice items and supported exact lists use the built-in answer key. Local AI grades are provisional: 95% exact-score agreement has not been verified for this model.

To check a deployment, download the model, wait for **Local AI ready**, submit a written answer and check its grade against the scheme. Use an answer that requires AI interpretation rather than exact-list matching when testing model accuracy.
