## Verification and rollback

Open `subjects/economics.html#revision` from this branch. Try topic 4.7, miss a question, retry from Mistakes Log and answer correctly. Start a mock and refresh to resume. Paper 1 has 40 questions, and Paper 2 presents the compulsory case plus four choices. Choose three Section B questions before submitting. The written-answer review saves versions and displays the existing question-specific guidance.

Local JavaScript smoke checks covered rendering, topic links, case-paper marks, and saving and clearing mistakes. The notes, flashcard and question-bank file hashes match the baseline. Revert the revision branch changes to remove the routes and assets.
